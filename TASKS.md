## 1. Назначение

Этот файл содержит задачи по проверке, разработке и проверке `EnglishVoiceTutor`.

Задачи связываются с требованиями из `specs/` и создаются на основе результатов аудита (`specs/audit.md`). Перед изменением существующей функциональности необходимо проверить её текущее состояние и подтвердить необходимость изменений.

Основные правила:

1. Сначала исследовать существующую реализацию.
2. Зафиксировать фактическое состояние проекта.
3. Сопоставить реализацию с требованиями спецификаций.
4. Создать или уточнить задачи на основе обнаруженных расхождений.
5. Перед реализацией проверить, что требования достаточно конкретны.
6. После реализации выполнить проверки и обновить статус задачи.

- **Приоритет:** P0
- **Требования:** MM-004, MM-007, MM-009

## 14. Правило актуализации

`TASKS.md` — живой документ.

После каждого изменения необходимо:
- убрать задачи, которые не нужны;
- разделить слишком крупные задачи;
- добавить задачи для обнаруженных несоответствий;
- указать зависимости между задачами;
- уточнить приоритеты;
- заменить `Blocked` на актуальный статус после решения вопроса;
- связывать новые задачи с конкретными идентификаторами требований.

Нельзя считать задачу обязательной только потому, что она присутствует в этом первоначальном плане.
